# Java Simple To-Do List

Jednoduchá a efektivní desktopová aplikace pro správu úkolů postavená na jazyce Java. Projekt demonstruje základní principy objektově orientovaného programování (OOP) a zajištění perzistence dat pomocí souborového systému.

## Klíčové vlastnosti
* **Kompletní správa úkolů:** Přidávání, prohlížení a odstraňování úkolů v reálném čase.
* **Perzistence dat:** Automatické ukládání do **CSV souboru**, což zajišťuje uchování dat i po ukončení aplikace.
* **Strukturovaný kód:** Implementace oddělené logiky pro manipulaci s daty a uživatelské rozhraní.

## Technologie
* **Jazyk:** Java (JDK 11+)
* **Storage:** CSV (Comma-Separated Values)
* **Struktura dat:** Objektový model reprezentující úkol (ID, popis, stav).
