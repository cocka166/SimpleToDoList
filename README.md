Toto je jednoduchá aplikace To-Do List napsaná v Javě. Aplikace umožňuje uživatelům efektivně spravovat své úkoly přidáváním, prohlížením a odstraňováním úkolů. Úkoly jsou uloženy v seznamu a ukládají se do CSV souboru, což zajišťuje, že data přetrvávají mezi jednotlivými spuštěními aplikace.

*********************************************************************

This is a simple To-Do List application written in Java. The application allows users to manage their tasks efficiently by adding, viewing, and removing tasks. Tasks are stored in a List and are saved to a CSV file, ensuring that the data persists between application sessions.
